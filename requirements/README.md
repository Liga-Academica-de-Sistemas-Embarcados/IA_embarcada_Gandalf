# Requisitos

Este diretório reúne os requisitos funcionais do Gandalf, um sistema embarcado para controle de acesso por identificação automática de veículos. As especificações descrevem o comportamento esperado da solução, que combina ESP32-CAM, Raspberry Pi, reconhecimento óptico de placas e consulta a uma base de dados de veículos autorizados.

Os requisitos são escritos em formato Gherkin para orientar o desenvolvimento, a integração entre os componentes e a validação do sistema.
